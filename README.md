## 🌟 Spotlight: FinSight AI

> *Built for ITERYX '26 Hackathon — Team Wizard*

```
📱 Flutter Frontend  ──►  🔧 Spring Boot API  ──►  🤖 FastAPI ML Service
        │                         │                          │
  JWT Auth                  MongoDB Atlas             OCR + SMS Parser
  Expense UI                REST Endpoints            Indian Bank NLP
  Analytics                 Data Processing           Spending Insights
```

**Key Features:**
- 📸 **OCR Receipt Scanning** — Extract expenses from photos instantly
- 📲 **SMS Auto-parsing** — Reads SBI, HDFC, ICICI, Axis & UPI transaction messages
- 📊 **Smart Analytics** — Visual dashboards with spending patterns
- 🔐 **JWT Authentication** — Secure, token-based auth system
- ☁️ **MongoDB Atlas** — Cloud-native, scalable data storage
