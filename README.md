## 🌟 Spotlight — FinSight AI

> *Built for ITERYX '26 Hackathon — Team Wizard 🧙*

**The problem:** Tracking daily expenses in India is painful — receipts pile up, bank SMSes get ignored, and manual entry is tedious.

**The solution:** FinSight AI automatically reads your receipts via camera OCR and parses your bank SMS messages to log expenses hands-free.

| Feature | Details |
|:--------|:--------|
| 📸 OCR Receipt Scanning | Snap a photo → expenses auto-extracted |
| 📲 SMS Auto-Parsing | Supports SBI, HDFC, ICICI, Axis, UPI formats |
| 📊 Smart Analytics | Visual dashboards with category-wise spending |
| 🔐 JWT Auth | Secure token-based login system |
| ☁️ Cloud Storage | MongoDB Atlas for scalable data |
